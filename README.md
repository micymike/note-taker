# Real-Time Voice Note Taker

## Overview
A powerful, user-friendly application that captures and transcribes audio in real-time, allowing you to take notes effortlessly during meetings, lectures, or while watching videos.

## Features
- 🎙️ Real-time audio transcription
- 💬 Live transcript display
- 💾 Save and manage notes
- 🎨 Modern, intuitive GUI

## Prerequisites
- Python 3.8+
- pip
- Virtual environment recommended

## Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/note-taker.git
cd note-taker
```

2. Create and activate a virtual environment
```bash
python3 -m venv venv
source venv/bin/activate
```

3. Install dependencies
```bash
pip install -r requirements.txt
```

## Running the Application
```bash
python main.py
```

## Usage
1. Click "Start Voice Note" to begin recording
2. Watch the live transcript update in real-time
3. Click "Stop" when finished
4. Save your note with a title

## Troubleshooting
- Ensure microphone permissions are granted
- Check internet connection for speech recognition
- Verify audio input device settings
